XELI ON DESK  -  beta v0.3
==========================

Xeli is a little blue desktop pet who lives on your taskbar.
He walks around, sits, naps, waves, blinks and looks around.


HOW TO START
------------
1. Unzip this folder anywhere (for example your Desktop or Documents).
2. Double-click "Xeli on Desk.exe".
3. Xeli drops onto your taskbar. That's it!

First launch on a new PC: Windows may show "Windows protected your PC".
That happens with every new program that isn't code-signed. Click
"More info", then "Run anyway". Your antivirus may also scan it the
first time.


CONTROLS
--------
  Drag            pick Xeli up (let go while moving to throw him)
  Click           Xeli waves (or wakes up)
  Double-click    Xeli jumps
  Right-click     menu: Properties, actions, Color, spawn more Xelis, About, Exit

Each Xeli can have his own color: right-click him -> Color
(Blue, Yellow, Pink, Green, Purple or Orange).


PROPERTIES
----------
Right-click Xeli -> Properties... to change:
  - his name
  - size (48 - 240 px)
  - walk speed
  - activity (Lazy / Normal / Hyper)
  - gravity
  - naps, shadow, always on top
You can also spawn up to 20 Xelis.

Settings are saved in "xeli_settings.json" next to the exe.


SECRETS
-------
There are 10 secrets hidden in Xeli. Can you find them all?
Properties and About show how many you have found.

Hint: try playing with him in ways the controls above don't mention...


HOW TO CLOSE
------------
Right-click Xeli -> Exit.

To start him with Windows: press Win + R, type  shell:startup  and put
a shortcut to "Xeli on Desk.exe" in the folder that opens.


REQUIREMENTS
------------
Windows 10 or 11. Nothing else to install.
Xeli uses very little CPU (about 0.1%) and around 20 MB of memory.


BETA NOTES
----------
This is a beta, so things may change. Known limits:
  - Xeli only walks on your main monitor.
  - Bigger display scaling (125% / 150%) has had less testing.
Found a bug or have an idea? Please report it on the GitHub or itch.io page.
